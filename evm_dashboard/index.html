EVM 指標の読み方

SPI/CPI ≧ 1.0 (良好)

予定よりも進捗が早く、あるいは予算（工数）に余裕を持って稼働できています。

0.9 ≦ SPI/CPI < 1.0 (注意)

わずかな遅れやコスト超過の傾向があります。タスクの調整が必要です。

SPI/CPI < 0.9 (危険)

深刻なスケジュール遅延、または工数の大幅超過が発生しています。対策が急務です。
