# EVM Project Dashboard | Redmine Integration

Redmineの日報ニュースコメントから「作業実績工数」と「チケット進捗率」を自動インポートし、EVM（Planned Value, Earned Value, Actual Cost）を算出して美しく可視化するローカルダッシュボードシステムです。

このフォルダを丸ごと別のPCにコピーするだけで動作するようパッケージングされています。

---

## 📂 フォルダ構成

本フォルダには以下のファイルが含まれています。

```text
evm_dashboard/
├── index.html              # ダッシュボード画面（メイン構造）
├── index.css               # ガラスモルフィズム等のモダンなデザインスタイル
├── app.js                  # グラフ描画・アコーディオン開閉等のフロントエンド制御
├── evm_data.js             # 同期されたEVMキャッシュデータ（同期実行で自動更新）
├── redmine_evm_tool.py    # 日報自動取り込み＆EVM集計エンジン（Python）
├── server.py               # ローカルWebサーバー 兼 同期API中継（Python）
├── README.md               # 本手順書
└── run_dashboard.bat       # ダブルクリックで一発起動するランチャースクリプト
```

---

## ⚙️ 前提条件（システム要件）

移行先のPCで動作させるためには、以下の環境が必要です。

* **Python 3.10 以上** がインストールされていること。
  * ⚠️ **重要**: インストールする際、必ず **「Add Python to PATH（Pythonを環境変数PATHに追加）」** のチェックボックスをオンにしてください。

## 🛠️ セットアップ手順（他PCでの設定）

#### 1. フォルダのコピー
* 本 `evm_dashboard` フォルダを丸ごと移行先PCの任意の場所（例: デスクトップや `C:\` ドライブ直下など）に配置します。

#### 2. Redmine接続設定の書き換え
* [redmine_evm_tool.py](redmine_evm_tool.py) をメモ帳やテキストエディタで開きます。
* 7〜9行目付近にある以下の設定項目を、移行先のRedmineサーバーに合わせて書き換えて保存します。

```python
# ========================================================
# 接続設定（接続先のRedmineに合わせて書き換えてください）
# ========================================================
api_key = "bfbf9f677c5e23db28d516d3119da9db6f536d44" # 連携用アカウントのAPIキー
base_url = "http://localhost:3000"                  # RedmineのベースURL
project_identifier = "system_project_20260604"       # 対象プロジェクトID（識別子）
```

## 🚀 起動方法

1. フォルダ内にある **`run_dashboard.bat`** をダブルクリックします。
2. コマンドプロンプトが立ち上がり、自動的にバックグラウンドでローカルサーバー（ポート8000）が起動します。
3. 自動的に規定のWebブラウザが立ち上がり、ダッシュボード画面 (`http://localhost:8000/index.html`) が表示されます。

* ※終了する際は、立ち上がったコマンドプロンプトのウィンドウを閉じるか、`Ctrl+C` を押してください。

## 📊 使い方

### 1. データの同期（日報の取り込み）
1. ダッシュボード画面の左メニューから「**連携ステータス**」を選択します。
2. 同期対象日（日報投稿日）を指定して「**同期を実行**」ボタンをクリックします。
3. ニュースからパースされた進捗データがRedmineに登録され、自動的にダッシュボード用のEVMデータも更新されます。
   * 日付を空欄にした場合は、過去の未処理日報が一括して処理されます。
   * 進捗の報告ルールについては、下記の「日報パースフォーマット」に従って記述してください。

### 2. 進捗と稼働実績の確認
1. ダッシュボードの左メニュー「**稼働実績と日報**」を開きます。
2. 上部パネル「**メンバー別・日別稼働実績 (h)**」にて、日報から抽出された日別の実績稼働時間が確認できます。
3. 下部パネル「**担当者別・チケット進捗推移 (%)**」にて、メンバーごとのアコーディオンを開閉して、担当チケットの日別の進捗率（%）の推移をヒートマップ形式で確認できます。

---

## 📝 日報パースフォーマット

Redmineのニュースにメンバーがコメント（日報）を追加する際は、以下のフォーマットに準拠して記載してください。

```text
【本日の作業実績】
#82 90% 6.0h
#83 30% 4.0h
```

* **記述ルール**: `#<チケットID> <進捗率>% [<実績工数>h]`
  * 例: `#82 90% 6.0h` ➡️ チケット#82の進捗率を90%に更新し、当日の作業工数を6時間登録します。
  * ※工数登録を伴わない進捗率のみの更新（例: `#83 30%`）もサポートしています。
